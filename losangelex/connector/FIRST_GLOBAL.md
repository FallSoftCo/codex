# Native first Global installation

lax-provision-native-global --spec /protected/native-profile.json prepares and
seals one existing bootstrapped Hollywood Global identity. Add --activate for
its first activation. The profile names the protected Hollywood installation
intent, local private API, native package/interpreter, approved model account,
host and admission budget, and optional approved environment profile.

The factory uses the existing host enrollment, purpose installer, collaboration
installer and portfolio policy. It creates no semantic scheduler or TUI session.
It prepares the actual UID, private histories and units before installing the
protected bridge/resource dependencies, then seals them before Global starts.
All credentials and original operation identities remain protected on disk.
The bridge reports systemd READY=1 only after its real socket is listening.
Infrastructure and agent starts retain original intents; uncertain starts are
inspected, never blindly repeated. Existing setup preserves native capture
configuration and Unix traversal permissions on reconciliation.

The r47 receipt proves a fresh one-room Global with three distinct native
histories, zero-input idle startup, unchanged PIDs on reconciliation, preserved
native capture configuration on host re-enrollment, and preservation of a
deliberately stopped test responder. Its explicit test-only restoration reused
the original native history. Existing production and original team workers were
preserved. The earlier r44 prototype failed before Global activation at socket
readiness and directory traversal; those original receipts remain retained.

This source does not certify a completed enterprise deployment. The original fresh r47 human API task also completed through reader, writer
and responder, with generation1 retained, all three inference permits released,
and independent readback of BOOT-SMOKE.md matching the published SHA-256.
Selected Git/SSH/provider routes, boot desired state, daily operation, phone
delivery and multi-host qualification remain separate gates.
An ordinary Hollywood restart must preserve explicit agent stops; do not add
blanket PartOf/BoundBy dependencies that restart or kill other agent work.
