# Original primary-input repair

An installed communication administrator can use
hollywood_reconcile_pending_inputs with an existing agent identity and exact
original pending delivery IDs. The tool reuses the current three-purpose
enrollment and the canonical administrative context-configuration endpoint.
It never reposts a request, claims work, starts services, creates contexts or
retries unknown/cancelled execution.

Native declarations, executable dispatch, original administrative child-stage
identity and durable recovery agree. An accepted response lost in transport is
recovered through the original administrative receipt; it does not cause a
second PUT. Purpose capability metadata excludes the legacy v2-only report
reconciliation tools that its executable catalog deliberately omits.

The SDK/HTTP/PostgreSQL receipt in qualification uses the current actual native
writer admission and rollback-only inbox fixtures. It exercises the shared
NativeToolSession, authentication, original administrative receipt recovery,
cached same-call result, non-admin rejection and cancelled-original rejection.
It starts no model and is not evidence of a model choosing this tool. The source
candidate is separate from the still-running dev88 native processes.
